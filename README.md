# AI-Powered-Career-Intelligence-Platform
The AI-Powered Career Intelligence Platform is developed as part of the Infosys Springboard Virtual Internship. It aims to help students explore career opportunities and make informed career decisions.

Key Features

Career Recommendations: Explore suitable career paths based on skills and interests.

Skill-Gap Analysis: Identify skills required for desired career roles.

Career Guidance: Understand potential career pathways and opportunities.

Learning Resources: Discover resources to support skill development.

Responsive UI: User-friendly interface built with Bootstrap.
